# 声のアトリエ · Vocal Range Trainer

声域測定・ピッチ分析・5トーン発声練習をまとめた、Android Chrome向けの個人用PWAです。

公開先： https://yuuuh26.github.io/vocal-range-trainer/

## 使い方

1. Chromeで開き、メニューから「ホーム画面に追加」。
2. 「測定を始める」を押し、マイクを許可。ひとりの声を静かな場所で測ります。
3. グラフは初期30秒。15秒・60秒・全体へ切替可能。左右にスワイプして過去へ移動し、「現在へ戻る」で追従を再開。
4. 終了後、必要な練習だけ「練習結果を保存」。履歴からグラフを再表示できます。
5. 発声練習ではお手本のあとに発声。終了位置はスケールの開始音で指定し、実際に鳴る最高音は画面に表示します。

## 実装

- 日本式／国際式の音名、Hz、cent差、目標音メーター。
- YINの正規化差分と放物線補間。55〜1200Hz、A4=440Hz。
- 小音量・信頼度フィルター。新しい音は2フレーム、7半音を超える飛びは3フレーム確認して採用。
- 同一音名350ms以上、信頼度90%以上、標準偏差15cent以下・幅60cent以下で安定音。
- ロングトーンの直近1秒の標準偏差と安定度。セッション平均は「安定条件を満たした区間のみ」の参考値。
- Workerで約20回/秒解析、グラフは最大約10回/秒。通常の履歴は約10点/秒。72000点を超えた長時間履歴は間引き、最低・最高の統計は別途維持。
- 5トーン：1–2–3–4–5–4–3–2–1、半音上昇／下降、手動／自動、停止・一時停止（同じキーのお手本から再開）。
- Web Audioで柔らかい倍音を含むガイド音を生成。再生中と800msの余韻待ち中は解析を停止。
- IndexedDBのアプリ専用DB、利用者が保存した結果のみ永続化。音声そのものは保存・送信しません。
- Markdown書き出し、ピッチ込みJSONバックアップ・追加復元（同一IDを上書きしない）。
- 専用PNGアイコン192/512とmaskable、noindex、manifest、オフライン用Service Worker。
- Service Workerはこのアプリのキャッシュだけを管理。更新は全タブを閉じたあと反映し、測定中の強制更新やDB削除は行いません。

## 検証

```sh
npm install
npm test
npm run test:integration
npx playwright install --with-deps chromium
npm run test:browser
```

- 純粋関数テスト：44.1/48kHz、低音〜高音、倍音優勢、雑音、微小音、ビブラート、音名、安定条件、スパイク除外。
- DOM統合テスト：65秒の合成入力を実際のYIN処理へ通し、全期間保持、表示窓、履歴操作、保存、練習の上昇・下降・手動・一時停止、目標音を検証。ここでのマイク・保存はテストダブルです。
- Chromium統合テスト：モバイル画面幅393px、仮想マイクのWAV入力、Worker、実際のIndexedDB再読み込み、コール＆レスポンス、ネットワーク遮断後の再起動を検証。
- GitHub Actionsでテスト成功後にPagesへデプロイ。初回のみリポジトリのSettings → Pages → SourceをGitHub Actionsへ設定する必要がある場合があります。

## 制約

- 合成音テストは実人声の精度保証ではありません。Pixel 9 Pro実機でのマイク特性、Bluetooth遅延、ホーム画面追加は実機確認が必要です。
- 同時に複数の声や伴奏がある場合、強い雑音、息だけの声では誤判定・未検出があります。ガイド同時解析は初期版に含みません。
- カメラ・録音・外部API・解析サービスは使いません。配信時の通常のWeb通信はGitHub Pagesに発生します。
- 画面を離れると測定を終了し、その時点までの結果を画面内に残します。ブラウザ自体が終了する前に保存してください。
- 永続ストレージ許可はブラウザ判断。履歴はブラウザのデータ削除で消えるため、大切なデータはJSONバックアップしてください。
- noindexは非公開化やアクセス制限ではありません。

## 開発メモ

ビルド不要のES Modules。ローカル起動は `npm start`。Service Worker対応ファイルを変更するときは `sw.js` のキャッシュバージョンも更新してください。
